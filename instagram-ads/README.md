# Instagram Ad Graphics

Three SVG files for your Instagram ad campaign, one for each facial service.

## Files

1. **the-edit.svg** - The Edit service (60 or 90 minutes) - Olive green accent
2. **heaven-earth.svg** - Heaven + Earth service (70 minutes) - Soft blue accent  
3. **the-remedy.svg** - The Remedy service (70 minutes) - Sage green accent

## How to Convert to Images

### Option 1: Browser (Easiest)
1. Open any SVG file in your web browser (Chrome, Firefox, Safari, Edge)
2. Right-click on the image
3. Select "Save image as..." or "Save picture as..."
4. Choose PNG or JPG format
5. The image will be saved at 1080x1080px (Instagram's square format)

### Option 2: Online Converter
- Use an online SVG to PNG converter like:
  - https://cloudconvert.com/svg-to-png
  - https://convertio.co/svg-png/
  - https://svgtopng.com/
- Upload the SVG file and download as PNG at 1080x1080px

### Option 3: Design Software
- Open in Adobe Illustrator, Figma, or Inkscape
- Export as PNG/JPG at 1080x1080px

- **Format**: Square (1080x1080px) - Instagram's standard post size
